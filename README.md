# Bryce's personal toolbox of utility functions

:warning: **This is my personal sandbox and is not intended for public use**

## Installation

Requires Python 3.8+.

```bash
pip install git+https://github.com/bryce-wedig/brypy.git
```

To install with development dependencies:

```bash
pip install "brypy[dev] @ git+https://github.com/bryce-wedig/brypy.git"
```

For local development:

```bash
git clone https://github.com/bryce-wedig/brypy.git
cd brypy
pip install -e ".[all]"
```

To build docs:
```bash
cd docs/
make html
```
